# Nuvio Hentai Scraper (18+)

Provider für Nuvio mit den Quellen hanime.tv, hentaihaven.xxx, hanime.red, a-hentai.tv.

## Installation
1. Eigenen TMDB-Key in `providers/hentai.js` (`TMDB_KEY`) eintragen.
2. In Nuvio → Einstellungen → Plugins diese Repository-URL hinzufügen:
   `https://raw.githubusercontent.com/h97667611-dotcom/nuvio-hentai-scraper/main/manifest.json`

## Hinweise
- Nur für Erwachsene (18+). Nutzung auf eigene Verantwortung.
- Das Plugin hostet keine Inhalte, es verlinkt nur auf Drittseiten.
- Seitenstrukturen ändern sich häufig; bei Ausfall die Quelle in `providers/hentai.js` anpassen.
